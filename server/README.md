# 共有サーバー（任意）

社外や自宅からも同じデータを使いたい場合だけ必要です。
**社内の共有フォルダで足りる場合は、これを設置する必要はありません。**

## これは何か

アプリの「③共有サーバー」モードで使う、データの置き場所です。
Cloudflare Workers（無料枠）の上で動き、データは Cloudflare KV に1件だけ保存されます。

- 保存されるのは、アプリの「バックアップJSON」と同じ内容ひとかたまりです
- 読み書きには合言葉（チームキー）が必要です
- 合言葉を知らない人は、アドレスを知っていてもデータを読めません

## 設置のしかた

```powershell
.\deploy.ps1
```

途中でブラウザが開くので、Cloudflare にログイン（アカウントがなければその画面で無料作成）して
「Allow」を押してください。あとは自動です。

終わると次の2つが表示されます。

- 共有サーバーのアドレス（例：`https://org-ops.〇〇.workers.dev`）
- 合言葉（チームキー）

この2つを、アプリの「設定・データ」→「会社のメンバーと共有する」に入力してください。
社内の全員が同じ2つを入れると、同じデータを見られるようになります。

合言葉を自分で決めたい場合：

```powershell
.\deploy.ps1 -TeamKey "しゃないあいことば"
```

## あとから合言葉を変える

```powershell
npx wrangler secret put TEAM_KEY
```

変更後は、全員のアプリ側の合言葉も入れ直してください。

## 費用

Cloudflare Workers と KV の無料枠に収まる想定です（1日10万リクエストまで）。
社員数十名で1日中使っても、通常は無料枠の範囲です。

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/api/meta` | 版数と更新時刻だけを返す（15秒ごとの確認に使う） |
| GET | `/api/data` | データ本体を返す |
| PUT | `/api/data` | データを保存する。`{ rev, payload }`。`rev` が古いと 409 |

すべて `X-Team-Key` ヘッダに合言葉が必要です。
`rev` に `-1` を送ると、競合を無視して上書きします（アプリの「自分の内容で上書きする」）。

## うまくいかないとき

- **「合言葉（チームキー）が違います」** … アプリ側の合言葉と、`wrangler secret put TEAM_KEY` で入れた値が違います
- **「共有サーバーに接続できません」** … アドレスの綴り（末尾の `/` は不要）と、デプロイが成功しているかを確認してください
- **`KV namespace (ORG_OPS) が設定されていません`** … `wrangler.toml` の `id` が空です。`deploy.ps1` を実行し直してください
